# Política de Reembolso — Aurora Cloud

A Aurora Cloud oferece reembolso integral em até **14 dias corridos** após a
contratação de qualquer plano, desde que o uso não ultrapasse 100 GB de
armazenamento ou 10.000 chamadas de API no período.

Após os 14 dias, reembolsos são avaliados caso a caso pelo time de suporte,
e normalmente só são concedidos em caso de indisponibilidade comprovada do
serviço (SLA abaixo de 99.5% no mês).

Planos anuais cancelados após o período de reembolso integral recebem
crédito proporcional aos meses não utilizados, descontada uma multa de
rescisão de 10%.

Para solicitar reembolso, o cliente deve abrir um ticket em
suporte@aurora.cloud com o número do pedido.
