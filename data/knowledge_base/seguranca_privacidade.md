# Segurança & Privacidade de Dados — Aurora Cloud

Todos os dados em trânsito são criptografados via TLS 1.3. Dados em
repouso são criptografados com AES-256, com chaves gerenciadas via KMS
dedicado por cliente no plano Enterprise.

A Aurora Cloud é compatível com LGPD e GDPR. Clientes podem solicitar a
exclusão completa dos seus dados (direito ao esquecimento) através do
painel em Configurações > Privacidade > Excluir minha conta. A exclusão
é processada em até 30 dias e é irreversível.

Não compartilhamos dados de clientes com terceiros para fins de
treinamento de modelos de terceiros. Dados de uso agregados e anonimizados
podem ser usados para métricas internas de produto.

Incidentes de segurança que envolvam vazamento de dados pessoais são
comunicados aos clientes afetados em até 72 horas, conforme exigido pela
LGPD (Art. 48).
